# 用户可见消息清单

本文列出插件可能发送给玩家的文字消息模板。`{名称}`、`{人数}`、`{金额}`、`{角色}`、
`{回合}` 等表示运行时替换值；按钮的 `action.data` 不属于可见文案。

## 文案约束

- 能通过按钮完成的操作，不在正文中展示完整指令。
- 房间创建、加入或退出后的操作区固定显示“加入 / 退出 / 开始”三个按钮。
- 主菜单不显示“退出房间”，大厅中以“查看状态”作为常用入口。
- 帮助正常情况下只发送规则卡图片，不发送文字；图片缺失时才发送错误提示。

## 插件入口与发送异常

- 《百万美金》目前仅支持 QQ 官方机器人群聊。
- 无法从消息中识别群或玩家身份，请稍后重试。
- 插件尚未初始化完成，请稍后重试。
- 暂时无法开局：{牌组校验错误}
- 处理指令时出错，请稍后重试或联系管理员查看日志。
- 缺少操作令牌，请重新点击按钮。
- 没有「{动作}」这个操作。请打开菜单查看当前可用操作，或通过帮助按钮查看规则卡。
- 按钮发送失败，请重新发送指令重试（秘密按钮不会以明文形式重发）。

## 主菜单

- `## 百万美金` / 本群还没有对局。/ 点「创建房间」开一局 3～8 人的银行抢劫桌游，点「帮助」可以先看规则卡。
- `## 百万美金` / 本局已经结束。/ 点「创建房间」可以开新的一局，点「帮助」查看规则卡。
- `## 百万美金（大厅，人数 {当前人数}/8）` / {人数提示}
- `## 百万美金（选角中）` / 选角按钮已经按玩家发出，每行只有对应玩家可以操作，选完请点按钮发送。/ 点「查看状态」可以看进度。
- `## 百万美金（谈判中，第 {回合} 回合）` / 直接在群里交涉，谈好后点「准备」；转账和退出是两件独立的事，都只影响你的人物和现金。
- `## 百万美金（谈判中，第 {回合} 回合）` / 你这一轮已经退出，等其他人谈完就行。
- `## 百万美金（{阶段}）` / 这一阶段不需要你操作，等结算结果即可。

人数提示只有两种：

- 还需要 {人数} 人才能开局（最少 3 人）。
- 人数已满足，可以开始游戏。

- 未实现的动作：{内部动作名}
